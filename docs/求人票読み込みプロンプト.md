# 求人票をClaudeで読み込むためのプロンプト(営業担当向け)

## 使い方

1. Claude(claude.ai)を開き、**求人票のPDF(または写真)を添付**する
2. 下のプロンプトをコピーして送信する
3. Claudeが出力したJSON(` ```json ` のブロック)を**丸ごとコピー**
4. 在日人材求人マッチング( https://seijj08.github.io/jinzai-matching/ )の
   「＋ 求人を登録」→「🤖 Claudeの解析結果(JSON)を貼り付けて反映」欄にペースト →「反映」
5. 内容を確認・修正して「保存」

※1つのPDFに複数の求人がある場合は、求人ごとにJSONが分かれて出力されるので、1件ずつ貼り付けてください。

## プロンプト(ここからコピー)

```

- 読み取れない項目は null にする。推測で埋めない
- 求人票に複数の求人が載っている場合は、求人ごとに別々のJSONコードブロックで出力する
- JSON以外の説明文は最小限にする

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| 貼り付けても「JSONが見つかりません」 | コードブロックの中身(`{` から `}` まで)が含まれるように全体をコピーする |
| 職種・夜勤などが反映されない | リストにない表記になっている。選択肢の表記(全角括弧含む)と完全一致が必要なので、手で選び直す |
| 月給が変な値になる | 「万円」の数値になっているか確認(23万円なら 23) |
